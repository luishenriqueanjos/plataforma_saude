# Plataforma de Hábitos Saudáveis e Performance de Treinos

## Problemas Abordados

### 1. App de Hábitos Saudáveis
Manter hábitos saudáveis no dia a dia costuma falhar por falta de acompanhamento e de lembretes consistentes. Esta ferramenta ajuda o usuário a cadastrar, monitorar e manter hábitos (como água, sono, exercício e alimentação) com base em metas diárias e no seu progresso ao longo do tempo.

### 2. Rastreador de Progressão e Periodização de Treinos
O acompanhamento de metodologias de treino estruturadas em blocos de notas genéricos impede a visualização rápida da progressão de carga e o cálculo de volume. Este sistema registra séries, gerencia divisões de treinos complexas e gera gráficos automáticos de evolução, substituindo anotações estáticas por métricas dinâmicas.

## Como Executar

1. Certifique-se de ter o Python 3 instalado no seu sistema.
2. Clone o repositório e acesse a pasta do projeto:
```bash
   git clone https://github.com/luishenriqueanjos/plataforma_saude
   cd plataforma_saude
```
3. Instale as dependências:
```bash
   pip install -r requirements.txt
```
4. Execute a aplicação:
```bash   
   python main.py
```
