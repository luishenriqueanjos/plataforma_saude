# Guia de Contribuição
Para manter o projeto organizado, siga as regras abaixo:

## 1. Ramificação (Branches)
- Crie uma branch própria a partir da `main` para cada tarefa:
  `feature/nome-da-funcionalidade`

## 2. Commits
- Escreva mensagens de commit claras no tempo presente (ex: `adiciona acompanhamento de agua e sono`).

## 3. Pull Requests (PR)
- Nenhum código entra direto na `main`.
- Abra um Pull Request e vincule ao item do backlog.
- **Aprovação obrigatória:** Todo PR deve ser revisado e aprovado por pelo menos 1 integrante da equipe antes do merge (conforme a Definição de Pronto no `PROCESSO.md`).
